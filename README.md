# Social Media Platform 🚀

A feature-rich, responsive full-stack social media web application built using **Python, Django, HTML5, CSS3, and Bootstrap 5**. This platform allows users to create accounts, share posts (PC setups, tech gadgets, study materials, nature photography), interact through likes and comments, and follow other users.

---

## ✨ Features

- 🔐 **User Authentication:** Secure user registration, login, and logout.
- 📱 **Interactive Home Feed:** Dynamic feed displaying posts, captions, like counts, and comments in real-time.
- 👤 **User Profiles & Follow System:**
  - View individual profiles with bio, profile pictures, and grid gallery.
  - Track total followers and following count.
  - Follow / Unfollow other users with instant toggle.
- 📸 **Post Creation:** Upload posts with image attachments and custom captions.
- ❤️ **Social Interactions:** Like/Unlike posts and add inline comments.
- 🎬 **Reels & Navigation:** Modern, responsive left-sidebar layout inspired by modern social applications.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Django Web Framework
- **Frontend:** HTML5, CSS3, Bootstrap 5, FontAwesome Icons
- **Database:** SQLite (Default Django ORM DB)
- **Version Control:** Git & GitHub
